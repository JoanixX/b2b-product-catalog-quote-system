# Guion de grabación: 75–90 segundos

Preparación: sesión nueva, abrir https://trazo-cotizaciones.pages.dev/. No introducir datos de clientes. En reuniones repetidas, `Restablecer ejemplo` → aceptar deja `EJ-001` recibido; para filmar la entrada desde cero usar sesión nueva.

| Tiempo | Clics exactos | Voz sugerida |
| --- | --- | --- |
| 0–10 s | Mostrar landing. | Soy Joaquín Alvarado. Esta es Trazo, una demo de un proceso de cotizaciones B2B con datos ficticios. |
| 10–22 s | `Ver el recorrido` → revisar ejemplo → `Registrar solicitud`. | El pedido reúne empresa, contacto, producto, cantidad y observaciones. En esta demo se guarda únicamente en este navegador. |
| 22–40 s | `Preparar borrador` → cantidad `10`, precio `1500` → `Guardar cambios`. | Antes de generar la propuesta, una persona ajusta y revisa cantidades, precio y condiciones. Aquí el importe de ejemplo queda en quince mil soles. |
| 40–53 s | `Aprobar borrador` → `Generar propuesta` → `Ver propuesta`. | La aprobación queda visible y se prepara una propuesta revisable. No se ha enviado ningún correo. |
| 53–65 s | `Imprimir o guardar PDF` → mostrar vista previa → cancelar o guardar PDF local. | El documento se puede imprimir o guardar desde el navegador. Sigue marcado como ejemplo sin validez comercial. |
| 65–76 s | `Volver al panel` → `Marcar en seguimiento`. | El estado permite ver cuál es la siguiente acción. Este seguimiento también es una simulación local. |
| 76–90 s | Clic en logo → bajar a contacto. | Puedo evaluar un piloto con tu marca y tus reglas comerciales. Aquí están mi contacto y mi portafolio. |

Después de grabar: `/demo` → `Restablecer ejemplo` → aceptar. No decir «enviado», «integrado con WhatsApp», «ya recibe clientes» ni atribuir ahorros o resultados. El piloto funcional es un entorno distinto; no aparece detrás de esta demo.
