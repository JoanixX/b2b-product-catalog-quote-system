# Frontend de la demo comercial

Astro + TypeScript + CSS. Consulta el [README principal](../README.md) para instalación, personalización, alcance y guion de grabación.

```powershell
npm ci
npm run dev
npm run build
```

Esta rama presenta un recorrido ficticio en el navegador y no necesita backend ni `.env`. La marca, los colores y los datos de ejemplo se editan en `src/lib/demo.ts`. Las páginas antiguas se conservan en `legacy-pages/` como referencia, fuera de las rutas activas.
